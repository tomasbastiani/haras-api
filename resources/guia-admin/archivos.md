# Archivos (Ver Archivos / Adjuntar Archivos)

> Los archivos que los vecinos adjuntan desde la app (por ejemplo, comprobantes de pago), asociados a un lote y a un período. Cómo los ve, filtra, descarga y elimina el admin.

## Qué hace el vecino

En **Menú → Adjuntar Archivos**, el propietario:
1. Elige el archivo.
2. Selecciona el **Lote** (sólo los suyos) y la **Carta** (el número de período de gastos comunes al que corresponde).
3. Escribe **Comentarios** (opcional). Su usuario se completa solo.
4. Toca **Crear**.

Se usa sobre todo para mandar **comprobantes de pago** u otra documentación de un período.

## Qué hace el admin

En **Menú → Ver Archivos** el admin ve **los archivos de todos** en una tabla: Lote, Carta Nº, Usuario, Comentarios, **Descargar** y **Eliminar** (🗑).

Filtros: **Lote**, **Carta Nº**, **Usuario** y **Comentarios**. En el celular se despliegan con el botón **Filtros**; **Limpiar** los borra.

- **Descargar**: baja el archivo a la computadora o el celular.
- **Eliminar**: pide confirmación ("¿Está seguro de que quiere eliminar este archivo?" → **Sí**). No se puede deshacer.

Ejemplo: para ver los comprobantes que mandó el lote 214 en el período 199, filtrar Lote = 214 y Carta Nº = 199.
