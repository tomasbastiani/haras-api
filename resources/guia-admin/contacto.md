# Contacto/Servicios

> La pantalla de teléfonos y mails útiles del barrio (Contactos y Servicios) y el formulario para mandar un mail a cada área.

Se entra desde **Menú → Contacto/Servicios**. Tiene dos pestañas:
- **Contactos**: las áreas del barrio, como Intendencia, Administración, Arquitectura, Guardia emergencias, Guardia portería y Family.
- **Servicios**: prestadores, como Family Service Center, Exactio y actividades deportivas para niños.

Cada tarjeta muestra el teléfono, el mail o el WhatsApp. Las que tienen mail tienen un botón **Enviar mail**, que abre un formulario con **Asunto** y **Mensaje**; el mail sale desde la app hacia esa área.

La lista de contactos está fija en el código de la app. Para agregar, quitar o corregir un teléfono o un mail, hay que pedírselo al soporte técnico: no hay pantalla para editarla.
